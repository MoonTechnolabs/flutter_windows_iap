## 0.0.1

* Initial release of `flutter_windows_iap`.
* Windows Microsoft Store APIs via method channel `com.moontechnolabs.flutter_windows_iap`.
* Supports `getProducts`, `makePurchase`, `checkPurchase`, `getAddonLicenses`, and `getPurchaseId`.
* Includes `OneStoreConfig` for Azure AD / One Store OAuth credentials.
